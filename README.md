# Task Helper

Интерактивный технический прототип по `PRD-voice-to-yandex-tracker.md`.

## Что реализовано

- Текстовый ввод и редактирование исходного текста.
- Локальное формирование черновика: заголовок, структурированное описание, дедлайн, приоритет, участники и спринт.
- Профили маршрутизации с обязательной доской.
- Выбор текущего, следующего и следующего через один спринта по календарным датам.
- Блокировка создания без обязательного спринта.
- Просмотр источника значений, уровня уверенности и истории созданных демо-задач.
- Безопасный демонстрационный режим: нет запросов к внешним API, токенов и рабочих данных.

## Запуск

Запустите сервер:

```powershell
npm start
```

## Граница прототипа

При первом входе сервер предлагает установить пароль от 12 символов. Он хранится в `.data/auth.json` как PBKDF2-SHA-512 хеш с уникальной солью; браузер получает только `HttpOnly`, `SameSite=Strict` сессию на 8 часов. Файл с данными исключён из репозитория.

Для внешнего развёртывания обязательны HTTPS и переменная `COOKIE_SECURE=true`. Обычный пароль не заменяет полномочия Яндекс Трекера: для будущего реального создания задач нужен защищённый серверный сервисный токен с минимальными правами или иной согласованный механизм интеграции. В текущем прототипе создание задачи имитируется и сохраняется в `localStorage` браузера.
